# Security Policy

## Supported Versions

Cooki UI components are designed as self-contained, source-first code assets. Security updates are applied directly to the canonical source files in the registry.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

We take security and memory safety very seriously. If you discover a security vulnerability, memory leak, or dependency issue in any Cooki UI component or the CLI tool:

1. **Do not open a public issue.**
2. Send an email to [security@cooki-ui.design](mailto:security@cooki-ui.design) or open a private advisory via GitHub's [Security Advisories](https://github.com/Nivethith-AK/Cooki-UI/security/advisories/new).
3. Include detailed steps to reproduce the vulnerability, including:
   - Component slug
   - Framework / runtime environment (e.g. Next.js 15, Vite, React 19)
   - Sample reproduction code or repository

### Response SLA
- Initial response within 48 hours.
- Fix or workaround deployed to the static registry within 5 business days.

Thank you for helping keep Cooki UI safe and reliable!
